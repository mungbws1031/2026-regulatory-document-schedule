# 2026 Regulatory Document Schedule

KGMP, EU IVDR, ISO 13485, MDSAP의 2026년 문서 제출·인증 유지·심사 준비 일정을 정리한 반응형 웹 캘린더입니다.

## Features

- 2026년 1월~12월 연간 일정
- 공식 기한과 내부 권장 일정 분리
- 규제별 필터: KGMP / EU IVDR / ISO 13485 / MDSAP
- 회사 인증서 만료일 및 심사일 입력에 따른 내부 준비일 계산
- PDF·인쇄 지원
- 공식 원문 링크 제공

## Important notice

이 사이트는 규제 업무용 일정 관리 보조자료입니다. 제품 등급, Legacy 여부, 인증서, NB·CB·AO 계약, 회사 SOP 및 관할기관의 최신 공식 문서를 우선 적용해야 합니다. 회사별 정보가 없는 일정은 확정 법정기한으로 간주하면 안 됩니다.

## Data privacy

사용자가 입력한 인증서·심사 날짜는 브라우저의 localStorage에만 저장되며 외부 서버로 전송되지 않습니다.
