IVDD 자가선언 → IVDR Class C
NB Written Agreement

IVDD에서 자가선언된 후 IVDR Class C가 된 Legacy IVD 중 2026년 5월 26일까지 Formal Application을 제출하고 전환조건을 충족한 제품에 한해 적용됩니다.

회사별 날짜가 필요한 항목

  • KGMP 적합인정서 만료일과 변경 발생일
  • ISO 13485 인증서 만료일·CB 심사일
  • MDSAP AO 심사일·NC 발행일·인증 만료일
  • 제품별 PSUR/PMPF/PER 기준일
  • IVD 앱 Design Freeze·V&V 완료·릴리스 목표일

일정구분규제업무실행 내용

공식 기한은 정확한 날짜 칸에 표시하며, 날짜가 회사별로 달라지는 내부 업무는 각 월 하단의 ‘월간 권장 업무’로 구분합니다.

공식 기한은 빨간 마커, 프로그램 권고는 초록 마커, 내부 권장 업무는 시작일~종료일 막대로 표시합니다. ← 좌우로 밀어 월별 일정 확인 →

1월부터 12월까지 월별 규제·인증·문서 업무를 시간 순서로 배치합니다. 일정을 누르면 제출·준비 문서를 확인할 수 있습니다.

일정 전에 문서 흐름부터 확인

제품 범위·분류 확정부터 Annex II·III 작성, GSPR·Risk Management·Performance Evaluation·V&V 추적성, RA/QA 승인과 NB 제출까지 연결했습니다.

보완은 다시 근거로 회수

Gap 또는 NB 질문이 생기면 단순 답변으로 끝내지 않고 영향평가·문서 개정·재검토·승인 이력으로 회수하는 구조입니다.
